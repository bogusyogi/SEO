## Historical claims superseded

- Fixed AI uplift percentages, platform source shares, mention correlations and precise answer-block word counts are not operating targets or promised outcomes.
- Training crawlers and search/citation crawlers have different purposes. A blanket crawler allow-list is not a valid policy.
- Structured data, `llms.txt`, crawler access and an eight-word query filter do not establish AI citation performance.
- Old hosting and per-brand live/built labels require fresh evidence. Current site policies and collection records own operational status.
- Ahrefs, Firecrawl and hosted AI-visibility products were referenced tools, not functionality supplied by the free standalone collectors. No web-wide competitor or backlink database is claimed.

## Dashboard boundary

`scripts/dashboard_export.py` projects an allowlisted read-only snapshot from existing portfolio evidence. The private `life` presentation host renders it at `/seo`. It does not hold Google/Bing credentials or call paid providers. The SEO implementation remains independent of that host.

Portfolio dashboard exposes Google query/page performance, GA4 organic metrics with tracking status, bounded crawl findings, PageSpeed scores, CrUX availability, Bing traffic, sampled backlinks and collection freshness. New windows accumulate reporting history; repeated reads of the same window do not fabricate a trend. The original manual no longer occupies a live route.
